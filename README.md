# Sonic & Software Portfolio

A professional, high-performance portfolio showcasing the intersection of **Sound Engineering** and **Software Development**. This project is built using **Next.js 16**, **React 19**, and **Tailwind CSS 4**, featuring a high-performance bento-grid layout and interactive 3D elements.

## 🛠️ Tech Stack

* **Framework**: Next.js 16.1.0 (App Router)
* **Styling**: Tailwind CSS 4 with PostCSS
* **3D Graphics**: Three.js with React Three Fiber & Drei
* **Animations**: Framer Motion
* **Icons**: Lucide React

## 📂 Project Structure

* **`/app/scientist`**: Focuses on technical engineering projects, featuring a C++ DSP Audio Processor and Matrix Algorithm Visualizers.
* **`/app/creative`**: Showcases music production, performance history, and integrated YouTube sets.
* **`/app/components`**: Contains reusable UI elements like the `Navbar`, `StarBackground`, and `Scene` for 3D rendering.
* **`/app/lib/data.ts`**: Centralized configuration for projects and social links.

## 🚀 Key Features

* **Integrated Media**: Direct YouTube set embedding on the Creative page for immediate playback.
* **Bento Grid Layout**: A detailed, responsive grid system for organizing professional experience and technical skills.
* **Professional Pedigree**: Highlights real-world experience as a Live Sound Engineer at **Fabric London**.
* **Scientific Visualization**: Real-time rendering of linear algebra concepts and signal processing tools.
* **Dynamic Backgrounds**: An interactive `StarBackground` component for a deep, immersive space aesthetic.

## 🔧 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/sashsutton/my-portfolio.git](https://github.com/sashsutton/my-portfolio.git)
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
